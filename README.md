# Rover Type A controller

Локальный веб-пульт для ровера типа A из файла `/Users/michael/Downloads/Ровер тип А.pdf`.

## Как управлять

1. Включите батарейный отсек на машинке.
2. Откройте пульт по локальному HTTP-адресу.
3. В поле `Шасси` уже стоит адрес нашего ровера: `http://192.168.2.23`.
4. Нажмите `Проверить`. Камера подставится из `/status` или как следующий IP-адрес.
5. Поставьте машинку на подставку и в блоке калибровки проверьте `M1`-`M4`.
6. Назначьте каждому мотору позицию `FL`, `FR`, `BL`, `BR` и включите инверсию, если колесо крутится в обратную сторону.
7. Управляйте стрелками на экране или клавишами `W A S D`, `Q E`, `Space`.

## Что делает пульт

- `GET /wheels?m1=...&m2=...&m3=...&m4=...&timeout=...` отправляет мощности от `-100` до `100` (GET с параметрами поддерживается по инструкции ровера).
- `GET /stop` останавливает шасси. GET-команды изменяют состояние робота; не открывайте их для проверки связи.
- `POST /servo` поворачивает камеру в диапазоне `0`-`180`.
- `POST /buzzer` отправляет тон или мелодию.
- `GET /sensors` читает сонар и датчики линии.
- Камера использует `/snapshot`, `/flash?v=...` и поток `:81/stream`.

Пульт повторяет команды движения, пока удерживается кнопка или клавиша. Это нужно потому, что `timeout` у ровера всегда останавливает движение автоматически.

## Задержки связи

- Одновременно отправляется только одна команда колёс. Пока она выполняется, сохраняется только последнее выбранное направление.
- STOP удаляет неотправленные направления и отправляется после завершения текущего запроса. Ожидание ответа на движение ограничено 1200 мс; при ошибке управление отключается до повторной проверки подключения.
- Отмена HTTP-запроса не отменяет команду, уже дошедшую до прошивки. При плохой сети остановка также может запаздывать; таймер движения робота остаётся включённым.
- GET-команды с отключённым кешированием избегают дополнительного CORS-запроса, необходимого для POST с JSON.
- Видео включается вручную кнопкой Stream, выключается квадратной кнопкой рядом с Shot. Shot получает один кадр.
- Автоопрос датчиков выполняется раз в секунду и пропускается во время движения. Незавершённые опросы не накапливаются.
- Поле «Ответ» измеряет полный HTTP-ответ, включая тело; это не ICMP ping.

Проверки логики отправки без обращения к роботу: `node --test tests/controller.test.cjs`.

## Ограничения

- Не отправляйте команды чаще одного раза в 50 мс.
- В этой версии управление заблокировано для всех шасси, кроме `192.168.2.23`.
- Камера также заблокирована на адрес нашего комплекта: `192.168.2.24`.
- Мощность ниже примерно `30` может не сдвинуть мотор.
- `valid: false` у сонара означает, что эхо не вернулось.
- Порог линии нужно подобрать на своей трассе.
